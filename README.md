# Сирена

Навчальний симулятор тривог на карті Росії. Не показує справжні тривоги.

## Запуск на комп’ютері

```bash
npm install
npm run dev
```

Сайт відкриється на порту 8080.

## Безкоштовна публікація на Vercel

1. Зайди на [vercel.com](https://vercel.com) і увійди через GitHub.
2. **Add New → Project** і вибери репозиторій `syrena`.
3. Натисни **Deploy**. Нічого в налаштуваннях міняти не треба.
4. За кілька хвилин з’явиться посилання на кшталт `syrena.vercel.app`.
